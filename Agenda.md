# Agenda

## ⚠️ Overdue

```tasks
not done
due before today
sort by due
sort by priority
```

## 📅 Today

```tasks
not done
happens today
sort by priority
sort by due
```

## ⏭ Upcoming

```tasks
not done
happens after today
happens before in 7 days
group by happens
sort by priority
```

## 📌 Scheduled, no deadline

```tasks
not done
has scheduled date
no due date
sort by scheduled
```

## 📥 Inbox / Unscheduled

```tasks
not done
no happens date
sort by priority
```

## 🔬 Research Tasks

```tasks
not done
(path includes 01_Projects) OR (path includes 02_Sources) OR (path includes 05_Experiments)
sort by due
```

## 💼 Business Tasks

```tasks
not done
(path includes 10_Business) OR (description includes #business)
sort by due
```
